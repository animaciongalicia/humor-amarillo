# Fotos de la web

Sube aquí las fotos (jpg, png o webp). La web las optimiza sola (webp, varios tamaños, carga diferida): una foto de 600 kB acaba pesando 20–100 kB en la web. Solo se publican las que se usan en alguna página; el resto se queda aquí sin afectar a la velocidad.

Para usar una foto, se llama por su nombre de archivo (sin extensión) en la página. Actualmente en uso:

| Foto | Dónde |
|---|---|
| `gladiadores-barna` | Portada y galería de Humor Amarillo |
| `IMG-1788` | Cabecera de Humor Amarillo |
| `pared-obstaculos-puños` | Cabecera de Packs y galería |
| `telaraña-765`, `puente-colgante-612`, `sumos-batalla`, `bolas-gigantes` | Galería de Humor Amarillo |

Sin foto todavía: Cena y fiesta (`cena-fiesta`) y Alojamiento (`alojamiento`). Se muestra un hueco "Foto pendiente".

## Antes de publicar una foto, comprueba
- Que no tenga logos, marcas de agua ni teléfonos de otras empresas.
- Que no salgan menores (la web es solo para adultos).
- Que tengas permiso de uso y de las personas que salen.
- Resolución: para cabeceras, mínimo 1200 px de ancho.
