# Fotos de la web

Sube aquí las fotos (jpg, png o webp), sin preocuparte del tamaño: la web las convierte a webp ligero con varios tamaños.

**Importante:** subir una foto aquí NO la publica. Solo se publican las que están registradas en `src/data/photos.ts`. Así no sale nada por error (marcas de agua, menores, fotos de terceros). Para usar una foto nueva, pídemelo o regístrala en ese archivo.

## Antes de publicar una foto, comprueba
- Que no tenga logos, marcas de agua ni teléfonos de otras empresas.
- Que no salgan menores (la web es solo para adultos).
- Que tengas permiso de uso y de las personas que salen.
- Resolución: para cabeceras, mínimo 1200 px de ancho.
