# Fotos de la web

Sube aquí las fotos (jpg, png o webp). La web las optimiza sola (webp, varios tamaños y carga diferida), así que puedes subir originales de buena calidad: ideal entre 1600 y 3000 px de ancho y menos de 5 MB cada una.

## Nombres para que se coloquen solas
| Archivo | Dónde sale |
|---|---|
| `hero.jpg` | Portada (Inicio) |
| `humor-amarillo.jpg` | Página Humor Amarillo |
| `cena-fiesta.jpg` | Página Cena y fiesta |
| `packs.jpg` | Página Packs |
| `alojamiento.jpg` | Página Alojamiento |

Mientras falte un archivo, esa página muestra un hueco "Foto pendiente". Formato horizontal (proporción 8:5 aprox.); se recorta al centro.

Importante: usa solo fotos propias o con permiso, y comprueba que las personas que salen están de acuerdo en que se publiquen.
