# Fotos

Suelta aquí fotos reales (jpg, png o webp) con estos nombres y se activan solas, optimizadas:

- `hero.jpg`        → portada de Inicio (horizontal, mínimo 1600 px de ancho)
- `humor-amarillo.jpg` → página Humor Amarillo
- `cena-fiesta.jpg` → página Cena y fiesta (Los 7 PC)
- `packs.jpg`       → página Packs

Sin archivo, la web se ve igual de bien sin foto. Necesitas permiso para publicar fotos donde salga gente.
